# Réutilisation du socle par l'application Secondaire et demandes de changement

Date : 2026-10-15. Modèles : `specs/002-application-ipes/socle-reuse-A.md`, `specs/003-application-primaire/socle-reuse.md`. **Légende** : C = couvert, P = partiel, N = à créer ; SS = demande de changement du socle (« Secondary Socle »), réalisée par l'agent propriétaire du module concerné, jamais par un agent Secondary. Chaque SS est **sans effet sur l'existant** : défaut = comportement actuel, colonnes nullable, méthodes et clés nouvelles seulement, les 5130 tests restent verts.

## 0. Constats transverses
1. **Contrats seulement** : `Apps/Secondary` n'importe que `Scholaris\Modules\Socle\<M>\Contracts\*` (`tests/Architecture/StandardsTest`) et ne lit aucune table du socle (`NoForeignTableReadTest`). Les écrans appellent directement les routes du socle pour ce qui est C (personnes, inscriptions, frais, paiements, appel, notes, conseils, documents). Secondary n'ajoute des routes `/secondary/...` que pour ses données et pour les API du CDC qui composent plusieurs services.
2. **Contrats déjà livrés pour Higher et réutilisés** : `Organisation\Contracts\{StructureWriter, AuthorizationRegistry, EnrolmentGuard, OrgUnitTree, SettingsReader, OrgUnitSettingsReader, CurrentPeriod, TypedPromotionPlanner}`, `People\Contracts\{PersonDirectory, EnrollmentDirectory, StructureEnrollments, TeachingScope, BirthInfo, ConsentChecker}`, `Assessment\Contracts\{CurriculumCatalog, RuleStrategy, RuleCalculator, RuleScopeLineage, ResultsDirectory, AdmissionDirectory, LatestPublishedAverages}`, `Billing\Contracts\{InvoiceIssuer, InvoicePayer, PaymentRequester, DebtorDirectory, EstablishmentBalances}`, `Documents\Contracts\{DocumentIssuer, ExtendedDocumentIssuer, IssuanceGuard, DocumentCatalog}`, `Scheduling\Contracts\{TimetableWriter, TimetableDirectory, TeacherClasses}`, `Attendance\Contracts\{AttendanceSummaryProvider, AttendanceCodes}`, `Staff\Contracts\{StaffDirectory, AssignmentWriter, TaughtHoursRecorder, VacationCalculator, VacationPayabilityCheck}`, `Messaging\Contracts\{Messenger, DirectNotifier, DirectionDirectory}`, `Integrations\Contracts\{CartescolaireExporter, TabularExporter, ConfiguredExportType, SmsGateway}`, `Audit\Contracts\AuditLog`, `Identity\Contracts\{UserPersonLink, RoleDirectory, RecentSecondFactor, PermissionScopes}`, `Platform\Contracts\{ApplicationAccess, ApplicationManifest}`, `Portals\Contracts\PortalSection`, `Reporting\Contracts\IndicatorProvider`.
3. **Points d'extension par clé de liste du conteneur** (jamais une liaison unique : `definitions.php` est fusionné par `array_merge`) : `platform.applications.secondary`, `billing.fee_kinds.secondary`, `portals.sections.secondary`, `portals.grading_todo.secondary`, `assessment.rule_strategies.secondary`, `assessment.rule_scopes.secondary`, `documents.issuance_guards.secondary`, `organisation.enrolment.guards.secondary`, `organisation.closure.checks.secondary`, `organisation.closure.promotion.secondary`, `reporting.indicators.secondary`, `reporting.dashboards.secondary`, `reporting.todo.secondary`, `integrations.export_types.secondary`, `staff.vacation.payability_checks.secondary`, `privacy.tenant_data_source.secondary`, `privacy.subject_data_source.secondary`, `secondary.document_types` (DocumentTypeProvider), `console.command.secondary-*`.
4. **Paramètres du socle utilisés sans changement** : `assessment.lifecycle` (cycle `draft → submitted → validated → locked → published`, plus état `not_evaluated` ; transition `validated → locked` avec `require_recent_2fa: true`), `assessment.segregate_lock = true`, `assessment.step = 0.25`, `assessment.absence_codes` (`fraud` effet `zero`, `exempt` effet `excluded`, `replacement` effet `retake`), `/calculation-rules` (version par structure de niveau, `strategy: secondary`, `councilProposals` du CDC), `attendance.notify_parents`, `billing.allocation_rule`.
5. **Mécanismes Higher recopiés** (dans `Apps/Secondary/Support` et `Policies`, pas partagés) : `WriteGate`, `GatedAction`, `HigherRoutes` → `SecondaryRoutes`, `Perimeter` + `ScopeResolver` + `ScopedBySchool` → `ScopedByClass` (section, cycle, niveau, classe, matière), `RoleMatrix`, `HigherApplication` → `SecondaryApplication`.

## 3. Ordre et regroupement
- **Tour a** (agents propriétaires, en parallèle) : W0S-1 Organisation (SS1, SS2) ; W0S-2 Billing + Documents (SS7, SS8, SS12, SS14) ; W0S-3 squelette Secondary.
- **Tour b** : W0S-4 Assessment (SS3, SS4, SS5, SS6 ; dépend de SS1, SS2) ; W0S-5 Identity + Messaging + Attendance (SS9, SS11, SS13, SS10 si retenu).
- Si le primaire a déjà réalisé PS1a/PS1b/PS4/PS5/PS6, SS1/SS3/SS5/SS6/SS11 se réduisent aux ajouts propres au secondaire (période `year`, types par nature de période, `line_extras`, variables supplémentaires).
