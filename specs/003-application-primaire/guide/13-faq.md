# 13. Questions fréquentes

## Connexion

| Problème | Solution |
|---|---|
| Je n'ai pas reçu le code d'activation par SMS | Vérifiez que l'école a enregistré le bon numéro. Attendez une minute puis redemandez le code. |
| « Le code a expiré » | Le code n'est valable que quelques minutes : redemandez-en un. |
| J'ai oublié mon mot de passe | Lien **Mot de passe oublié ?** sur la page de connexion, ou demandez à l'administrateur de l'école. |
| La connexion est bloquée | Trop de mots de passe faux : attendez la fin du délai affiché. |
| « Accès refusé » sur une page | Votre rôle ne permet pas cet écran. Vérifiez le rôle choisi en haut de l'écran, ou demandez à la direction. |

## Paramétrage et inscriptions

| Problème | Solution |
|---|---|
| L'inscription est refusée dans une classe | La classe n'a pas d'autorisation d'ouverture valide aujourd'hui : **Administration > Autorisations d'ouverture** (chapitre 02). |
| « Une personne existe peut-être déjà » | Un enfant semblable existe : reprenez sa fiche si c'est le même, sinon choisissez **Personne différente**. |
| Comment changer le garant d'un élève ? | Secrétaire ou administrateur : ouvrez la fiche de l'élève (**Personnes et inscriptions**), section **Parents et garants**. Ajoutez le nouveau **Garant financier** et cochez **Retirer l'ancien garant financier** (chapitre 03, 3.2). Les factures déjà émises ne changent pas ; les relances et les reçus vont au nouveau garant ; s'il n'a pas de référence de paiement famille, la caisse la lui émet. |
| L'étape « Frais & paiement » ne montre pas de montant | Pour la secrétaire, c'est normal : la facture d'inscription est émise dès la validation (chapitre 03). Sinon, la grille des frais de la classe n'existe pas encore : la comptable la crée. |
| La feuille de compétences n'a aucune compétence | Le référentiel du niveau est vide : **École primaire > Référentiel** (chapitre 02). Vérifiez aussi que la classe est rattachée au bon niveau. |

## Appel et compétences

| Problème | Solution |
|---|---|
| Pas de réseau pendant l'appel | Faites l'appel normalement : il est gardé sur le téléphone et part au retour du réseau (chapitre 05). |
| La liste d'appel est vide | Ouvrez l'écran une fois avec le réseau. Si elle reste vide, la classe n'a aucun élève inscrit : la direction vérifie les inscriptions de la classe. |
| L'import du fichier de compétences est refusé | Une cellule est fausse : l'écran indique laquelle. Corrigez le fichier et réimportez. Rien n'a été enregistré. |
| Je ne peux plus modifier la feuille | Elle est verrouillée : utilisez **Corriger** pour envoyer une demande à la direction. |

## Conseil et bulletins

| Problème | Solution |
|---|---|
| **Valider le conseil** est refusé | Les feuilles de compétences de la classe ne sont pas verrouillées. |
| Je dois changer une appréciation après l'émission | Émettez un **rectificatif** (chapitre 07). Le bulletin d'origine reste dans l'historique. |
| Une famille n'a pas reçu le SMS « bulletin disponible » | Lisez le motif dans le résumé de la publication (chapitre 07) : numéro manquant, famille désinscrite des SMS ou consentement retiré. Le SMS est un message essentiel : il part sans consentement recueilli, sauf si l'école a désactivé cette règle. Le bulletin reste visible dans l'espace des parents. |
| Le parent ne voit pas le bulletin | Le bulletin doit être **publié**. Le parent doit être garant financier de l'enfant. |

## Caisse

| Problème | Solution |
|---|---|
| « Aucune caisse n'est ouverte » | Ouvrez la caisse (chapitre 04). |
| Référence de paiement inconnue | Vérifiez la référence sur la facture ou demandez-la à la comptable. |
| Un paiement saisi par erreur | Ne le refaites pas. Demandez une annulation : elle doit être validée par une deuxième personne. |

## Qui contacter ?

1. D'abord la **direction de l'école** ou son **administrateur**.
2. Ensuite, l'administrateur contacte l'équipe SCHOLARIS en donnant : l'écran, l'heure, le message affiché.
