# Guide : directeur d'école

Vous dirigez une école de l'institut (santé, gestion…). Vous validez les décisions académiques de votre école.

## Vos écrans
**IPES > Paramétrage académique**, **Maquettes**, **Admissions**, **Inscriptions**, **Notes**, **Délibérations**, **Documents officiels**, **Vacations**.

## Saisir une maquette
1. Ouvrez **Maquettes** et créez la version de la filière, du niveau et de l'année.
2. Ajoutez les unités d'enseignement (UE) puis leurs éléments constitutifs (EC) : intitulé, crédits (ou coefficients pour un BTS), volumes horaires.
   *Capture : éditeur de maquette avec le total de crédits par semestre.*
3. Le directeur académique **publie** la maquette. En licence, un semestre fait 30 crédits ; un BTS rattache chaque matière à une épreuve de l'examen national.
4. Dès qu'une note existe, la maquette ne change plus : on crée une nouvelle version.

## Décider d'une admission ou d'une inscription sous réserve
1. **Admissions** : ouvrez la candidature, vérifiez les pièces. « Admis » est impossible tant que la pièce exigée (diplôme) n'est pas vérifiée.
2. **Inscriptions** : seul vous pouvez inscrire un étudiant « sous réserve financière », avec un **motif** obligatoire.
3. Au-delà de deux inscriptions dans le même niveau, vous seul pouvez accorder une **dérogation**.

## Tenir le jury
1. **Délibérations** : constituez le jury du groupe et du semestre (**Constituer le jury**) ; vous le présidez.
2. Simulez, puis clôturez la séance (**Clôturer la séance**). Cette étape demande la double authentification.
3. **Signer le procès-verbal**, puis **Publier les résultats**. La publication est refusée tant que le PV n'est pas signé.
   *Capture : écran du jury avec les signatures.*

## Documents officiels
Certificats, relevés, cartes : **Documents officiels**. Vous signez ceux qui l'exigent. Un document annulé affiche son motif sur la page de vérification (QR).

## Points d'attention
- Une note verrouillée ne se modifie que par une **demande de correction motivée**, avec pièce.
- Vos choix sont tracés dans le journal d'audit.
- La reprise de données (étudiants, notes) est réservée aux personnes qui ont l'autorisation `higher.migration.manage` ; elle s'applique avec la double authentification.
