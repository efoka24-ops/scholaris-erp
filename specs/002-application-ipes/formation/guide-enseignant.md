# Guide : enseignant

## Vos écrans
**IPES > Enseignement** (emploi du temps), **Présences et discipline** (appel), **Notes**, **Mes vacations**.

## Faire l'appel
1. Ouvrez **Présences et discipline** : choisissez la séance du jour de votre groupe.
2. Marquez les absents et les retards ; les autres sont présents.
3. Validez l'appel avant la fin de la séance.
   *Capture : liste d'appel d'un groupe avec les cases absent / retard.*
Sans réseau, l'appel est gardé sur le téléphone et envoyé quand la connexion revient.

## Saisir et soumettre les notes
1. Ouvrez **Notes** (« Évaluations et notes ») : choisissez l'évaluation de votre EC et de votre groupe.
2. Saisissez chaque note de 0 à 20 (au **quart de point**) ou un code d'absence (ABJ justifiée, ABI injustifiée, NA, FR). Vous pouvez aussi **importer un fichier** (**Importer**, modèle fourni).
3. Enregistrez. Quand toutes les cases sont remplies, **Soumettre**.
4. Le responsable **valide** (**Valider**), puis **verrouille** (**Verrouiller**, avec double authentification). Les étudiants voient leurs notes après **Publier aux étudiants**.
   *Capture : grille de notes avec le cycle « brouillon, soumise, validée, verrouillée, publiée ».*

## Corriger une note après verrouillage
Faites une **demande de correction** motivée avec une pièce : elle passe par une double validation. Les requêtes d'étudiants sont traitées dans un délai de 7 jours.

## Cahier de textes et vacations
Après chaque séance, saisissez le contenu et **signez**. Vos heures validées chaque mois forment votre bulletin de vacation (**Mes vacations**).

## Points d'attention
- Vous ne pouvez saisir que vos EC et vos groupes : sinon refus (403) et trace dans le journal.
- Une saisie incomplète peut retarder le paiement de vos vacations.
