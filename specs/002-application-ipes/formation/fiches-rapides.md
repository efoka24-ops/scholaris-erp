# Fiches rapides

Une fiche par action fréquente. Les mêmes fiches sont dans l'application (menu **Aide** de l'IPES). Cinq étapes au plus.

## Saisir les notes
Rôle : enseignant. Écran : **Notes**.
1. Ouvrez **Notes** depuis l'accueil de l'application IPES.
2. Choisissez l'évaluation de votre EC et de votre groupe.
3. Saisissez chaque note de 0 à 20 (au quart de point) ou un code d'absence (ABJ, ABI, NA, FR).
4. Enregistrez, puis **Soumettre** quand toutes les cases sont remplies.
5. Après verrouillage, une correction passe par une demande motivée avec pièce.

## Faire l'appel
Rôle : enseignant. Écran : **Présences et discipline**.
1. Ouvrez **Présences et discipline**.
2. Choisissez la séance du jour de votre groupe.
3. Marquez les absents et les retards ; les autres sont présents.
4. Validez l'appel avant la fin de la séance.
5. Sans réseau, l'appel reste sur l'appareil et part au retour de la connexion.

## Encaisser un paiement
Rôle : caissier. Écran : **Frais et paiements > Comptes de scolarité**.
1. Ouvrez votre caisse, puis le compte de l'étudiant (nom ou matricule).
2. Vérifiez le solde et l'échéancier affichés.
3. Choisissez le moyen : espèces, Orange Money, MTN MoMo, virement.
4. Saisissez le montant exact et validez **une seule fois**.
5. Remettez le reçu numéroté à l'étudiant ou au garant.

## Inscrire un étudiant
Rôle : scolarité. Écran : **Inscriptions**.
1. Ouvrez **Inscriptions** et choisissez la candidature admise.
2. Choisissez le groupe et le mode d'études.
3. Créez l'inscription : le contrat pédagogique est préparé.
4. Vérifiez les frais d'inscription, puis validez : le matricule est attribué.
5. Remettez la fiche d'inscription et la carte d'étudiant (**Documents officiels**).

## Publier les résultats
Rôle : directeur d'école, jury. Écran : **Délibérations**.
1. Vérifiez que toutes les notes du semestre sont verrouillées.
2. Ouvrez **Délibérations** et tenez le jury du groupe (**Constituer le jury**).
3. Clôturez la séance, puis faites **signer le procès-verbal** par le président.
4. **Publier les résultats** : refusé tant que le procès-verbal n'est pas signé.
5. Les étudiants sont prévenus et voient leurs résultats dans leur espace.

## Reprendre un fichier de données (équipe SCHOLARIS avec la scolarité)
1. Téléchargez le modèle du jeu (étudiants, UE, soldes, personnel, notes).
2. Remplissez-le (CSV UTF-8 séparateur « ; » ou Excel), sans ligne d'exemple.
3. **Simulation** : lisez le rapport ligne par ligne, corrigez, recommencez jusqu'à zéro erreur.
4. **Application** avec la double authentification : tout ou rien.
5. En cas de mauvais fichier : **annulation** du lot avec un motif (sauf soldes d'ouverture).
