# 14. Glossaire

Les mots et sigles de l'application IPES, expliqués simplement. Les renvois indiquent le chapitre où le terme est utilisé.

| Terme | Explication |
|---|---|
| **2FA** (double authentification) | Deuxième vérification à la connexion : un code à 6 chiffres affiché par une application du téléphone, en plus du mot de passe. Obligatoire pour les rôles sensibles (01). |
| **ABI** | Code de note : absence injustifiée à une évaluation. Compte 0 (06). |
| **ABJ** | Code de note : absence justifiée. Donne droit à une épreuve de remplacement ou au rattrapage (05, 06). |
| **Abonnement** | Contrat de l'institut pour utiliser l'application IPES : essai gratuit, puis paiement mensuel. S'il n'est pas payé, l'application passe en lecture seule (11). |
| **Admis avec dettes** | Décision de fin d'année : l'étudiant passe en année supérieure mais doit repasser les UE manquantes (inscrites d'office) (07). |
| **Admis sous réserve** | Décision d'admission en attente d'une pièce ; expire au bout de 30 jours sans la pièce (03). |
| **Affectation** | Lien entre un enseignant, un EC, un groupe et une nature de séance (CM, TD, TP), avec un volume d'heures. Elle détermine ce que l'enseignant voit et saisit (05). |
| **Anonymat** | Les copies d'examen portent un numéro au lieu du nom ; le service des examens lève l'anonymat après le verrouillage (06). |
| **Autorisation MINESUP** | Arrêté du ministère de l'Enseignement supérieur qui autorise une filière et ses niveaux. Sans autorisation valide, pas d'inscription (02). |
| **BTS** | Brevet de technicien supérieur : diplôme national d'État, préparé en deux ans. L'institut délivre seulement une attestation de fin de formation (08). |
| **Cahier de textes** | Registre des séances : date, contenu, travail demandé. Signé par l'enseignant, contre-signé ensuite. Condition du paiement des heures (05). |
| **Capitalisation, UE capitalisée** | Une UE acquise l'est définitivement, avec ses crédits, même en cas de redoublement (03, 07). |
| **Cas limite** | Étudiant dont la moyenne est très proche d'un seuil (par défaut à moins de 0,5 point) ; signalé par la simulation (07). |
| **CC** | Contrôle continu : devoirs et interrogations pendant le semestre. Par défaut 40 % de la note d'EC (06, 07). |
| **CM** | Cours magistral. Compte 1,5 HETD par heure (05, 08). |
| **Compensation** | Une UE sous 10 est acquise quand la moyenne du semestre atteint 10, sauf note éliminatoire (07). |
| **Compte de scolarité** | Situation financière d'un étudiant pour une année : facture, échéancier, paiements, reçus, solde (04). |
| **Consentement (partage avec le garant)** | Accord de l'étudiant majeur pour que son garant voie ses notes et absences. Révocable (03, 10). |
| **Contrat pédagogique** | Liste des UE qu'un étudiant suit dans l'année : obligatoires, optionnelles choisies, dettes, capitalisées (03). |
| **Convention de stage** | Contrat tripartite entre l'étudiant, l'entreprise et l'école (DOC-20) (08). |
| **Crédits (ECTS)** | Valeur d'une UE ou d'un EC en LMD. Un semestre vaut 30 crédits, une année 60, une licence 180 (02, 07). |
| **Délibération** | Réunion du jury qui arrête les résultats d'un semestre ou d'une année (07). |
| **Dérogation** | Autorisation exceptionnelle du directeur d'école : 3e inscription dans un niveau, levée d'une interdiction de composer (03, 05, 07). |
| **DOC-xx** | Numéro d'un document officiel du catalogue (DOC-01 à DOC-32), par exemple DOC-09 relevé semestriel. Liste complète au chapitre 07 (7.15). |
| **Duplicata** | Réimpression d'un document déjà émis, avec la mention « Duplicata » ; le numéro d'origine est conservé (07). |
| **EC** (élément constitutif) | Matière ou partie d'une UE, avec ses crédits et ses volumes horaires. On saisit les notes par EC (02, 06). |
| **Échéancier** | Découpage d'un montant en tranches datées ; par défaut 3 tranches de pension (15 octobre, 15 janvier, 15 avril) (04). |
| **École (interne)** | Subdivision de l'institut (école de santé, école de commerce…), avec son directeur et son code (02). |
| **Empreinte (SHA-256)** | Code calculé sur le contenu d'un PV ou d'un export ; toute modification ultérieure le change, ce qui révèle une falsification (07). |
| **Établissement** | Dans SCHOLARIS, l'institut lui-même (type « Supérieur ») (01, 11). |
| **Filière** | Formation (par exemple Comptabilité et finance), avec un régime fixe (LMD, BTS, HND, certificat) (02). |
| **FR** | Code de note : fraude. Compte 0 et saisit le conseil de discipline (05, 06). |
| **Garant** | Parent, tuteur ou personne qui soutient un étudiant ; voit sa situation financière et peut payer (10). |
| **Groupe** | Subdivision d'un niveau (G1, G2…) ; unité de l'emploi du temps et de l'appel (02). |
| **HETD** | Heure équivalent travaux dirigés : unité de paiement des vacations. 1 h de CM = 1,5 HETD ; 1 h de TD = 1 HETD ; 1 h de TP = 0,75 HETD (08). |
| **HND** | Higher National Diploma : diplôme national d'État (système anglophone), équivalent du BTS (08). |
| **Hors ligne** | Fonctionnement sans connexion : l'appel et les notes sont gardés sur l'appareil puis envoyés (01, 06). |
| **IPES** | Institut privé d'enseignement supérieur. C'est aussi le nom de l'application « Supérieur » dans SCHOLARIS. |
| **Journal d'audit** | Registre inaltérable de toutes les actions sensibles (qui, quoi, quand, pourquoi) (13). |
| **Lettre (grille de lettres)** | Note littérale d'une UE (A+, A, B+… F) avec ses points, selon la grille de la tutelle (07). |
| **LMD** | Licence (3 ans, 180 crédits), Master (2 ans de plus), Doctorat : organisation des études en semestres, UE et crédits (02). |
| **Maquette** | Programme d'une filière pour un niveau et une année : semestres, UE, EC, crédits ou coefficients, volumes horaires (02). |
| **Matricule** | Numéro unique et définitif de l'étudiant, attribué à la validation de la première inscription, par exemple 26EC-CF-0042 (03). |
| **Mention** | Appréciation de la moyenne : Passable (10 à 12), Assez bien (12 à 14), Bien (14 à 16), Très bien (16 et plus) (07). |
| **MGP** | Moyenne générale pondérée en points : moyenne des points des UE (selon la grille de lettres) pondérée par les crédits ; sur 4 (07). |
| **MINESUP** | Ministère de l'Enseignement supérieur du Cameroun. |
| **NA** | Code de note : non autorisé à composer (assiduité insuffisante). Compte 0 (05, 06). |
| **Niveau** | Année d'études dans une filière (L1, L2, BTS1…) (02). |
| **Note éliminatoire** | Note d'UE en dessous de laquelle aucune compensation n'est possible (par défaut 7) (07). |
| **Périmètre** | Partie de l'institut sur laquelle s'exerce un rôle : tout l'institut, une école, un département, une filière ou un groupe (11, 12). |
| **Points de jury** | Points ajoutés par le jury à la moyenne de semestre d'un étudiant, plafonnés (par défaut 0,5), motivés et inscrits au PV (07). |
| **Profil documentaire** | En-tête, logo, couleur et langue des documents d'une école (07). |
| **PV** (procès-verbal) | Compte rendu officiel d'une séance (jury de délibération, soutenance, conseil de discipline), signé (05, 07, 08). |
| **Quitus financier** | Document qui atteste qu'un étudiant ne doit plus rien ; exigé pour la soutenance, l'attestation de réussite, le transfert (04). |
| **Quorum** | Nombre minimum de membres présents pour qu'un jury puisse délibérer (07). |
| **QR (code de vérification)** | Carré imprimé sur un document ; scanné, il ouvre la page publique qui dit si le document est authentique (07). |
| **Rattrapage** | Seconde session pour les EC non validés ; la note de rattrapage remplace l'examen, le CC est conservé (07). |
| **Régime** | Système d'études d'une filière : LMD, BTS, HND ou Certificat. Ne change jamais (02). |
| **Règlement des études** | Paramètres d'évaluation et de passage d'une école pour un régime et une année ; figé à l'ouverture des inscriptions (02). |
| **Relevé de notes** | Document officiel des résultats d'un semestre (DOC-09) ou d'une année (DOC-10), émis après signature du PV (07). |
| **Requête** | Contestation d'une note publiée par l'étudiant, dans un délai (7 jours par défaut) (06, 10). |
| **Réserve financière** | Inscription validée par le directeur d'école malgré des frais d'inscription non payés, avec un motif (03). |
| **RG-xxx-n** | Référence d'une règle de gestion du cahier des charges (par exemple RG-ACA-1). |
| **Simulation** | Calcul des résultats d'un jury sans rien enregistrer ; aussi, essai d'une reprise de données sans rien écrire (07, 09). |
| **Soutenance** | Présentation orale du mémoire de stage devant un jury d'au moins trois membres (08). |
| **TD** | Travaux dirigés. Compte 1 HETD par heure (05, 08). |
| **Tiers payeur** | Entreprise, bailleur ou parrain au nom duquel la facture d'un étudiant est établie (04). |
| **TP** | Travaux pratiques. Compte 0,75 HETD par heure (05, 08). |
| **Tutelle (université de tutelle)** | Université publique qui encadre une filière LMD d'un IPES et délivre le diplôme ; une par filière et par année (02, 08). |
| **UE** (unité d'enseignement) | Ensemble d'EC, avec des crédits ; acquise si sa moyenne atteint 10 (ou par compensation) (02, 07). |
| **Vacataire, vacation** | Enseignant payé à l'heure ; l'état mensuel de ses heures validées est la vacation (08). |
| **Verrouillage** | Étape qui fige les notes d'une évaluation ; ensuite, seule une demande de correction motivée peut les changer (06). |
