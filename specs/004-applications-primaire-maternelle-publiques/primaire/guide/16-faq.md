# 16. Questions fréquentes

## Connexion et téléphone

| Problème | Solution |
|---|---|
| Je n'ai pas reçu le code d'activation | Vérifiez le numéro enregistré par l'école ; redemandez le code après une minute. |
| L'écran demande un code personnel sur l'ordinateur | Le code est propre à chaque appareil (téléphone ou ordinateur) : créez-en un pour cet ordinateur (chapitre 01, 1.6). |
| J'ai oublié mon code personnel | Après cinq erreurs, l'appareil est effacé. Reconnectez-vous avec le réseau et créez un nouveau code. Les appels non envoyés sont perdus : refaites-les. |
| Mon téléphone est perdu ou volé | Prévenez tout de suite le directeur : il révoque le téléphone inscrit. Changez votre mot de passe depuis un autre appareil. |
| « Accès refusé » | Votre rôle ne permet pas cet écran : vérifiez le rôle choisi en haut. |

## École, classes, élèves

| Problème | Solution |
|---|---|
| Aucune inscription n'est possible | Vérifiez la **fiche de l'école** (chapitre 02) et l'**autorisation d'ouverture** de la classe (chapitre 03). |
| Le directeur ne voit pas **Générer les unités** | Le réglage du ministère réserve le référentiel au niveau national : adressez-vous à l'Inspection générale ou à l'administrateur fonctionnel (chapitre 07). |
| L'élève n'a pas d'identifiant national | L'école n'est pas rattachée à son territoire : demandez-le à l'administrateur fonctionnel (chapitre 02). |
| « Un élève semblable existe déjà » | Ouvrez la fiche existante ; si c'est un autre enfant, cochez **C'est un autre enfant** avec un motif. |
| Comment changer le garant d'un élève ? | Le directeur le demande à l'administrateur du client. Celui-ci ouvre la fiche de l'élève dans **Personnes et inscriptions**, section **Parents et garants** : il ajoute le nouveau **Garant financier** et coche **Retirer l'ancien garant financier** (chapitre 04, section 4.3). Les factures déjà émises ne changent pas ; les relances et les reçus vont au nouveau garant ; s'il n'a pas de référence de paiement, la caisse la lui émet. |
| Une ligne du registre papier est refusée | Les autres lignes sont inscrites. Corrigez la ligne refusée et renvoyez-la seule. |
| Je ne peux pas désigner le titulaire | L'enseignant doit figurer dans le **Personnel** de l'école. |

## Appel et évaluation

| Problème | Solution |
|---|---|
| « La liste des élèves de cette classe n'est pas disponible » | Ouvrez la classe une première fois avec le réseau. |
| Des appels restent « en attente » | Retrouvez le réseau puis touchez **Envoyer maintenant**. Ne refaites pas l'appel. |
| « conflit (rien n'est écrasé) » dans les saisies en attente | Quelqu'un a modifié la grille entre-temps. Rechargez, vérifiez, puis **Renvoyer** ou **Abandonner**. |
| « Aucune unité d'apprentissage n'est prévue pour ce niveau » | Le directeur doit **Générer les unités** (chapitre 07). |
| Le bulletin publié contient une erreur | Le directeur réédite un **Rectificatif** au même numéro (chapitre 07). |

## APEE, examens

| Problème | Solution |
|---|---|
| Un parent n'a pas payé l'APEE : peut-on retenir le bulletin ? | **Non.** La cotisation est volontaire et n'a aucun effet sur la scolarité. Un frais exigé est à signaler à l'inspection. |
| Une dépense est « en attente de pièce » | Cliquez sur **Joindre la pièce** et saisissez sa référence. |
| Un candidat est « bloqué » | Son acte de naissance n'est pas vérifié. Régularisez l'acte puis demandez à l'inspection de valider le candidat. |
| L'école ne voit pas ses résultats d'examen | Ils s'affichent seulement après la publication par la délégation. |

## Qui contacter ?

1. L'enseignant contacte le **directeur**.
2. Le directeur contacte l'**inspection d'arrondissement**.
3. L'inspection contacte l'administrateur fonctionnel, qui s'adresse à l'équipe SCHOLARIS (écran, heure, message affiché).
